Overdrachtsdocument –🏡 B&B Website
1. Algemene projectinformaties:
   - Projectnaam : 🏡 B&B Website
   - Opdrachtgever : 
   - Doel van het project: Een B$B website maken
   - Korte samenvattig : Jij, als hoofdgebruiker kan alle pagina's editen , jij kan tekst en afbeeldingen verwijderen , editen of toevoegen op alle pagina's via de admin pagina. Jij kan ook contact berichten bekijken en wie wat heeft gereserveerd. Als klant kan jij de website bekijken , een of meerdere kamers reserveren in de beschikbaare datums en tijden ,dat kan via reserveren pagina. Jij kan ook een review geven, dat staat bij het einde van elke pagina.Op de contact pagina kan jij  algemene vragen naar de hoofdgebruiker sturen.

   - Einddatum: 26/06/2026
